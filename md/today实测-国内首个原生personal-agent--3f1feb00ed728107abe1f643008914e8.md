**Today，算得上国内首个原生 Personal Agent 应用。**
所谓原生，就是刚创立之初，就是奔着这个目标去的。
国内其他的被贴上 Personal Agent 标签的产品，或多或少，是因为 Personal Agent 火了。
才往那个方向靠的。
我记得，**早在 7 月份，Today 就开始通过白名单邀请进行体验测试，打磨产品。**
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275480/mpclipper/2026/10/06/81d911347d278b09b6ebf0ee692f99af_640.png)
到9 月24日，才正式开放下载使用。
不说别的，Today 开放使用，就直接提供 3 个桌面端系统、2 个手机端系统和网页版的多端使用。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/3522952ab15c17270897dd88d0c86ccf_640.png)
是为了保持横跨你多个设备的一致体验。
针对一个新团队、新产品来说，其实是很难的。
**Today 是齐俊元离开豆包后的首个创业项目。**
作为创立过办公协同产品Teambition，主导过阿里云盘，负责过豆包 PC版等多个产品线的产品人。
**他把他这几段经验，合并到了 Today 中。**
**还把Today打造成记得住你、会帮你主动办事的个人 AI 助理。**
Today，要做中国版的 Muse。
Today，是今天，表示今天要处理的事情的意思。
Today 的 slogan ：**懂你所想，为你先行。**
Today is your day。

# 2、界面整体介绍
进入 Today 首页，我们看到 Today 布局，不像 AI 办公 Agent 那样。
**这是左右均分两栏式。**
左侧是 AI 助理的对话区。
右侧是侧边栏，用来展示 AI 助理生成的成果或进行设置，可收起。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/546049afb4c7c41e5a47524154aae194_640.png)
**对于新人或者长期使用 AI 办公 Agent 的用户来说，Today 客户端的交互方式，刚开始有点难适应。**
需要花点时间，逐步习惯。
我们看到，右侧侧边栏，**有固定的 Today、任务、记忆、coco（我给 AI 助理取的名）栏目。**
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275482/mpclipper/2026/10/06/ed56308c1ea04af1099f0dde7b13d489_640.png)
**Today栏，是今天个人生活、学习、工作简报。**
每天早上、晚上会给你发一份简报，进行你当日工作安排和总结。
安排和总结，来源你授权空间中文件的变化，和你和 Today 的当日沟通安排。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/6af450698e0321a585a2b44c74f1b9f5_640.png)
但每天给我规划和总结的内容挺多的，让我看起来，有点焦虑。
**任务栏下，是你给 AI 助理安排的，在后天、在云端跑的任务。**
对于简单对话，对话框中快速完成回答的，不会在这里显示。
对于较为复杂的任务，云端跑的任务，会在这里显示。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/c3c7504d7e3334829a8deb7a76ef880f_640.png)
**任务下，也可创建定时任务。**
定时任务下，有很多的样例模板。
点击可直接到将提示词写入左侧对话框，给AI 助理发指令执行。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/aad346d9657f199e3ebf5e68540b0822_640.png)
**记忆下，是 AI 助理对你的整体记忆，你的健康数据展示，以及在使用 Today 过程中生成的记忆文件。**
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275480/mpclipper/2026/10/06/b3877dcbbe988c5000c8e46eaf19339d_640.png)
可以看到，记忆文件有很多，有工作的、项目的、生活的、学习的、健康的、设备的、AI 助理 coco 的各种。
每执行一个任务，Today 会自动判断，是否要新建或更新及记忆库。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/73519cc05d84c17623e41c5333e0b376_640.png)
记忆库自动按照各位维度组织好，这是长期记忆文件，是 Today 的负责决策的大脑，是 Today 主动找你推进事务的基础。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275480/mpclipper/2026/10/06/00ac04daad56e8c2e40c34ab601c6cb0_640.png)
**AI 助理「coco」栏，是你的AI 助理的每日日记，不可修改。**
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/708037f8c043f0fd6df06d8685947075_640.png)
AI 助理 coco 的日记，让她更拟人化了。

# 4、任务执行
那Today 具体的任务执行情况如何呢。
Today 的助理工作，其实分成了两部分。
**1）主动推进的部分**
**Today 基于你的信息、资料和记忆，在你主动开口前，就会帮你安排事务。**
等你来确定和推进下一步行动。
Today 下的晨间简报、晚间简报，就是这个就是这个机制。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275482/mpclipper/2026/10/06/eb52a809e0197e5639f90b1e5dce93df_640.png)
会主动盘点你在 Today 上关注和问过的事，列出思路、步骤，等你确认推进。
因为我让她帮我规划过公众号接下来的内容。
所以接下来的早间简报、晚间简报，都是推进我处理此事。
**还会主动推进和你相关的信息给你，让你确定是否加入接下来行动中。**
比如她知道我在运营公众号后，会主动推送和我公众号定位有关的内容给我。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/40e7211640560f9537ce8b708c2c8789_640.png)
并且还可直接帮你把公众号内容思路、框架完全搭出来。
你只需要截图填充就行。并且帮你出了个核实清单，等你一项一项确认。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275484/mpclipper/2026/10/06/3c453cb98a87eb20b76e83721cecf565_640.png)
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/397ea8934891e5655cec58bff06ea649_640.png)
她在一步一步推进你做你很关注的事。
你要做的事决策和给出目标。
**2）带着指令去执行的部分**
你有具体任务时，可直接告诉AI 助理，让她执行具体指令。
简单对话，当前对话框中完成回复。
**需要一段时间处理的任务，会建立成云端任务，云端运行，不影响你当前操作。**
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/bffb91c2ce37f959764b0fa2ff58f55e_640.png)
比如我写微信小微的文章时，没有合适的带小微 logo 的公众号头图。
我让她帮我做。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/5b000a259c3f8c3eefc52cb5f26962d0_640.png)
她在云端自动执行，执行完后告诉我结果，并自动更新了记忆。
给我生成了不同尺寸、不同形态的微信小微的 logo 配图。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/faaa9466258b9de07bef912aa5a7fb13_640.png)
效果挺好，不愁微信小微的 logo 了。
我让她帮我总结 9 月份公众号发文数据。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275481/mpclipper/2026/10/06/1bb30ad06437c8235c3c9e274d62d9a1_640.png)
它告诉我虽然 9 月比 8 月总阅读降低了-34.86%，主要是因为 8 有 10 万+的大爆款。
9 月分享上升了 70.63%、收藏上升了 57.93%，渠道结构反而更健康了。
并且给出了详细的数据佐证。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791275482/mpclipper/2026/10/06/6ed55c8dea0b0870066f1d527de48434_640.png)
并且，AI 助理的记忆，是实时更新的。
跟着你的任务走。
# 5、Today 体验小结
使用 Today 后。
这个国内首个原生的 Personal Agent。
是一个符合国内使用习惯的 Personal Agent。
和 AI 办公 Agent 完全不一样的体感。
她提供了多个终端入口，还可以连接微信使用。
**做到了随时随地、随身携带。**
她主动沉淀围绕你的记忆。
从你授权的资料中，从和你的每次互动中，自动更新记忆，记忆长期存储。
**做到越使用越懂你。**
她给自己开了一台云电脑，在线 24 小时运行。
她把任务隐入后台运行，不让你在当前窗口等待，干完活主动告诉你。
**做到云端运行，自动干活。**
她不等你开口，就提前规划事务，整理成清单和方向，等你确认。
**做到积极主动参与你的生活和工作规划，而不是被动执行。**
她会自己写日记，写复盘，记下你说过的话，很拟人化。
她是你的生活管家，工作搭子，学习伙伴。
**做到照顾你的方方面面，而不只是工作。**
因为是国内Personal Agent 产品。
产品操作和应用链接，都符合国内用户习惯。
**整个使用过程，是很舒服的。**
但在使用过中。
**存在的一个关键点：**
如果你不开放数据给她，她可能围绕那点有限的资料和历史对话，来回倒腾，给你建议和安排。
你会发现，很多事情不在点上。
但随着你给她授权的数据越多，连接的应用越多，对她开放的权限越大。
她的主动性就越强，越能抓住重点，处理事情也越符合你的预期，越让你省心。
你看你愿意把多少数据授权给她，来换取方便。
**这是一个取舍，这也是一个信任建立的过程。**
只有她真的帮你办事，让你省心，少出错。
你才放心把个人数据授权给她。
**这是和 AI 办公 Agent 很大的不同。**
你给 AI 办公 Agent 的数据，是围绕工作开展的，是和办公相关的，是可公开或半公开的。
你给 AI Personal Agent 的数据，是围绕你个人的，是和你相关的，比如健康的，邮箱的，相册的，电脑各个存储空间里的，不少是个人敏感数据。
在使用 AI 办公 Agent 时，你是不用把这些交出去的。
**这是产品定位决定的。**
要做你的 Personal Agent，就得往 Personal（个人的，私人的） 上走。
这背后是隐私，是安全，是信任。
是最难的，最有挑战的，也是最有想象力空间的。
Today，作为国内首个原生 Personal Agent。
对于探索和落地国内的 Personal Agent 应用，有了个好的开始。
