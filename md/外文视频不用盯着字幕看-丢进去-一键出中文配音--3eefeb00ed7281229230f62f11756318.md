看一场外文的技术分享，眼睛得一直黏在字幕上，稍不留神就漏掉一句；想把内容转成中文给同事或学生看，要么自己一句句念，要么花钱找人配。
pyVideoTrans 是 GPL-3.0 的中文开源项目，Star 约 1.9 万，09-20 刚发 v4.13。它把「语音识别 → 字幕翻译 → 多角色配音 → 音视频合成」这条流水线一次走完，而且全程能用国内的模型服务，也能全跑本地。
## 先看效果
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1790997460/mpclipper/2026/10/03/35516c33fbb461f82184a97c4dfdea34_640.jpg)
一段两个人对话的英文视频丢进去，出来的是：中文字幕已经挂上，原声换成了中文配音——而且两个说话人是两种不同的声音。它分得清哪句话是谁说的。
一眼说给同事听，就是这句：一段外文视频进去，中文配音出来，连谁在说话都分得清。
## 连谁在说话，它都分得清
这一下是它最该被记住的地方。
它带说话人分离（speaker diarization）：先分辨这段音频里有几个角色，再给每个角色配一个不同的音色。多角色视频最怕的就是全片一个声音念到底，听两句就分不清谁在讲了——这一步直接把那个问题解决了。你想换音色也能自己指定。
第二个让我愿意留下它的理由是：这条链路每一步都能停下来改。识别完可以看字幕对不对，翻译完可以改那一行译得不好的，配音前能换音色。不是「一键跑完、错了只能重来」那种黑盒——做视频的人都知道，翻译错一句就得整段重跑有多烦。
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1790997460/mpclipper/2026/10/03/1795779c4ae37b967f91c49f3192195e_640.jpg)
第三个是模型选择对国内很友好，这是我愿意推荐它的实际原因：语音识别可以选本地 Faster-Whisper，也可以选阿里通义、字节火山；翻译可
顺带一句带过：还有个人声分离、字幕合并、音视频对齐的工具箱，支持命令行无头跑和浏览器 WebUI。但这些不是今天要记住的点。
## 我的判断：谁该试，谁别碰
值得试的是这几类：做自媒体、经常要把外文内容做成中文版的；手上有一堆英文培训录像、会议回放要翻的；看外文技术视频学习、想顺便留一份中文版的；以及在意数据不出本机、愿意全跑本地的人。
但有几件事得先说清楚，它们是我判断里最硬的部分：
**门槛是它最大的问题，我不打算替它掩饰。** 第一次用要下语音识别模型、要配一个翻译服务、要有 ffmpeg。Windows 有预打包的 exe 能省掉 Python 这一关，但「装完就能出片」这种期待请放低。
**它不做下载。** 视频得是你自己的、或者你有权利处理的。别把它当成视频下载工具使——它不是。
**声音克隆有边界。** 它集成了 F5-TTS、CosyVoice、GPT-SoVITS 这类零样本克隆模型。我只提醒一句：**克隆你自己的声音**，别拿别人的声音干这个事。
**没有显卡会慢。** 想本地跑，README 写的是需要 CUDA 12.8 和 cuDNN 9.11；没有独显就走在线 API，或者接受本地慢慢跑。
**解压路径别带中文和空格。** README 里特意标了这条（比如解压到 `D:\pyVideoTrans`），也别直接在压缩包里双击运行。
好消息是维护状态相当扎实：仓库建了快三年，当前 open issues 只有 13 个，不是那种发完就跑的项目。
门槛偏高：Windows 用户下预打包版能省一半事，但模型和一个翻译服务仍然要你自己准备。
## 怎么开始
**先看它长什么样（零安装）**
打开 https://pyvideotrans.com 看界面截图和功能说明，先确认这条流水线是你要的。这一步我实测过，国内直接能开（约 1.4 秒返回）。
**Windows：下预打包版，不用配 Python**

- ✦从 https://github.com/jianchang512/pyvideotrans/releases 下最新的压缩包
- ✦解压到**没有中文、没有空格**的路径，比如：

```plain text
D:\pyVideoTrans
```

- ✦双击文件夹里的 sp.exe 启动（别在压缩包里直接运行）
- ✦想用 GPU 加速，先装好 CUDA 12.8 和 cuDNN 9.11

**macOS / Linux：源码部署**
```plain text
git clone https://github.com/jianchang512/pyvideotrans.git
cd pyvideotrans
uv sync
uv run sp.py
```
**先跑一条最短的链路（约 1～3 天体验）**

- ✦翻译服务先填一个你手上的（DeepSeek、通义百炼都行；想不出网就用本地 Ollama）
- ✦配音先选免费的 Edge-TTS，跑通了再考虑换
- ✦拿一段 1～2 分钟、两个人的英文视频试，看完是不是真的配成了两种声音

只跑通一段一分钟的视频，也够判断值不值；完整试一轮建议 1～3 天。成功标准：出来的中文字幕不用大改，而且你能听出是两个人在说话。卡在模型下载或 ffmpeg 上，留言 **系统 + 报错前半句**，我一条条看。
