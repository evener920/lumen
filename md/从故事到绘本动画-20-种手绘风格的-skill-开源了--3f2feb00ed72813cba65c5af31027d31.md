## 01 它做什么
你有一段故事文本，想做成手绘风格的动画视频，但不会画画，也不会做动画。
它把整个流程封装成一个 Skill，装进 Codex 或 Claude Code 之后，说一句中文就能跑完全套。
核心能力：

- 中文故事自动分句、动态分镜
- 每句生成对应的黑白线稿，再渲染成彩色插画
- 输出 1080×1440 竖屏 H.264 视频，适合短视频平台
- 默认静音画面轨，配音和 BGM 后期补

## 02 20 种手绘风格
内置 20 种可切换的视觉风格，覆盖从儿童绘本到商业科普的多种场景。
**偏情感叙事：**

- 彩铅日记漫画（默认）：黑色毡尖笔轮廓，低饱和彩铅乱涂，大留白
- 情绪叙事淡彩速写：靛蓝松散速写，透明淡彩，单一暖橙焦点
- 暖光童画绘本：柔软水粉，暖边光，蓬松形状
- 北欧低饱和水粉绘本：丹宁蓝与芥末黄，哑光颗粒
- 墨线淡彩绘本：清晰墨线，轻薄水彩，角色表演突出

**偏知识科普：**

- 极简黑白线条讲解：米白纸，细黑单线，火柴人
- 小豆人涂鸦信息图：黑色圆豆人，单一橙色强调
- 白板讲解动画：白底黑线，少量红蓝标记
- 暖色几何扁平绘本：简化几何块面，暖色平涂

**偏童趣风格：**

- 五岁儿童蜡笔坏画：歪扭比例，线条不闭合，涂出边界
- 潦草家庭投稿蜡笔：家长歪线稿，孩子粗乱上色
- 真实蜡笔纸实拍：可见纸纹，蜡质结块，大量漏白

**偏个性表达：**

- 水墨写意：宣纸，浓淡干湿，飞白枯笔
- Zine 孔版拼贴：复印颗粒，撕纸拼贴
- 粗粝木刻社论插画：高反差刻痕，套色偏移
- 鼠标烂涂鸦：锯齿鼠标线，荒谬比例

每种风格都有示例图，生成故事时由原文和角色锁定来控制人物、场景与动作的一致性。
## 03 两种使用方式
**方式一：故事文本 → 动画**
```plain text
使用 $story-to-handdrawn-video 把这段故事生成可后期配音的手绘动画。

（粘贴故事文本）
```
故事文本默认一个完整句子一个节拍。想控制节奏，直接在故事里按句分行即可。
**方式二：图片 → 动画**
```plain text
使用 $story-to-handdrawn-video 把这几张图片按顺序生成手绘动画：
/absolute/01.jpg /absolute/02.jpg /absolute/03.jpg
```
上传已有漫画页或插画，保持原顺序和构图生成动画。
还支持翻书效果（右下角卷页）和预览模式（720×960 快速确认效果，再出正式版）。
## 04 怎么上手
技术栈是 Remotion + Node.js，需要一些环境准备，但不复杂。
```plain text
# 1. 克隆项目
git clone https://github.com/gnipbao/story-to-handdrawn-video.git
cd story-to-handdrawn-video
npm ci
npm run check

# 2. 安装 Skill 到 Agent
cp -R skill-package/story-to-handdrawn-video ~/.claude/skills/

# 3. 设置渲染器路径
export STORY_VIDEO_PROJECT=/absolute/path/to/story-to-handdrawn-video
```
环境要求：Node.js 20+、Python 3.10+、FFmpeg、Chrome。
图片生成默认走 Codex Image2，不需要 API Key。如果要用 OpenAI API，设置 `OPENAI_API_KEY` 环境变量就行。
## 05 适合什么人
**内容创作者**：想把故事文案变成绘本动画，发抖音、小红书、B站，不用学动画软件。
**教育科普作者**：白板讲解风格、极简线条风格，做知识类短视频效率很高。
**品牌方**：有机轮廓、暖色扁平、Zine 拼贴，适合品牌故事和生活方式内容。
**亲子领域**：儿童蜡笔风格、彩铅日记，做睡前故事动画很合适。
默认输出是静音画面轨，配音和 BGM 留给后期。这也是作者的有意设计——画面和音频解耦，方便灵活处理。
