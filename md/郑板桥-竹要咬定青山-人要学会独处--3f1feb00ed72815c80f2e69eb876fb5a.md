# 01 一根竹子，一场雪
清朝有个画家兼诗人，叫郑板桥。
他画了一辈子竹子，也写了两首截然不同的诗。
一首写竹子：立根在破石头缝里，千磨万击，任尔东西南北风。
一首写雪：晨起开门，雪满大山，日光都是冷的，屋檐的冰溜子还没化，梅花被冻住了，他站在门口看了很久，说：这种清孤，不一般。
第一首，是写给别人看的：我郑板桥，骨头硬。
第二首，是写给自己看的：我郑板桥，心里孤。
# 02 千磨万击还坚劲
**《竹石》**
**咬定青山不放松，立根原在破岩中。**
**千磨万击还坚劲，任尔东西南北风。**
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791256055/mpclipper/2026/10/06/8c4d100856010d3d7a22f35ef543fb0d_640.jpg)
这是一首题画诗，题在郑板桥自己画的那幅竹石图上。
"咬定青山不放松"——一个"咬"字，竹子不是"长"在山上，是"咬"在山上。牙关紧咬的咬。
"立根原在破岩中"——它扎根的地方，不是沃土，是破碎的岩石缝。没土，没水，没靠山，只有石头。
"千磨万击还坚劲"——风吹它，雨打它，霜冻它，多少回了，它还是那个劲儿。
"任尔东西南北风"——四面八方的风都来，随便你从哪边吹，我不倒。
这首诗的口气，硬得像在跟谁叫板。
竹子是郑板桥的招牌。他画竹，画的从来不是竹子本身，是他自己：宁可食无肉，不可居无竹；竹子的节，是他的骨节；竹子的瘦，是他的清瘦。
《竹石》是他人生的宣言：你看我一身毛病、半生蹭蹬，可你动不了我。
写这首诗的郑板桥，是一个倔老头。
# 03 郑板桥：一辈子不服软的人
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791256054/mpclipper/2026/10/06/55f2028215ce16284a31adb13920cdba_640.jpg)
郑板桥，名燮，字克柔，江苏兴化人，"扬州八怪"之一。
他是真的"怪"。
科举考了一辈子：康熙年间中秀才，雍正年间中举人，乾隆元年才中进士——这时候他已经50岁了。
放到今天，就是考公考到五十岁终于上岸。上岸干什么？当七品芝麻官，去山东范县、潍县当知县。
当官他也没学会圆滑。潍县闹饥荒，他开仓放粮，先斩后奏，得罪了上司和豪绅；他又不肯给上面送礼，最后干脆辞官不干。
临走那天，潍县的百姓夹道相送。他画了一幅竹子送给他们，题诗：
"衙斋卧听萧萧竹，疑是民间疾苦声。些小吾曹州县吏，一枝一叶总关情。"
一个小县官，半夜听到风吹竹子，都以为是百姓在哭。
他给自己的印章刻了四个字，后世人人都会背：难得糊涂。
但懂他的人知道，郑板桥从来没有糊涂过。他只是在那个官场里，装糊涂。
辞官之后，他回到扬州卖画为生，画竹、画兰、画石，落款常写"板桥郑燮"。
这样一个一辈子不肯服软的人，到了晚年，写下了一首跟《竹石》完全不一样的诗。
# 04 一种清孤不等闲
**《山中雪后》**
**晨起开门雪满山，雪晴云淡日光寒。**
**檐流未滴梅花冻，一种清孤不等闲。**
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791256055/mpclipper/2026/10/06/eb7c538f62cdf8796fcd8f62633775e3_640.jpg)
一个雪后的早晨，郑板桥推开门。
"晨起开门雪满山"——一夜大雪，山全白了。
"雪晴云淡日光寒"——雪停了，云淡了，太阳出来了。可那太阳光，是冷的。雪把光反得刺眼，也把寒气反得透骨。
"檐流未滴梅花冻"——屋檐下的冰溜子（冰凌）还挂着，没开始滴。院子里的梅花，也被冻住了。花是冻的，时间是冻的，整个世界都凝住了。
"一种清孤不等闲"——站在这雪后的山门口，郑板桥心里涌起一种感觉：清孤。清，是干净，也是冷清；孤，是独自一人，也是无人可语。不等闲，不是寻常的意思——这种清孤，不是谁都能懂的。
这首诗，一个字都没有提到竹子的硬气。
没有咬，没有坚劲，没有东西南北风。只有冷，只有静，只有一个老头站在雪地里，看了一会儿，把门又关上了。
写《竹石》的那个人，和写《山中雪后》的这个人，是同一个郑板桥。
# 05 硬与孤，都是郑板桥
![image](https://res.cloudinary.com/dqvoyeo3x/image/upload/v1791256054/mpclipper/2026/10/06/c087dd2fe144dc5ad60af79c4ec64da3_640.jpg)
《竹石》向外，对着全世界：我咬定青山，我不倒。
《山中雪后》向内，对着自己：我站在雪里，我很孤。
一个写的是"劲"，一个写的是"冷"。
一个连风都奈何不了他，一个连太阳都照不暖他。
很奇怪吗？不奇怪。
一个人对世界越硬，回到独处时，往往越孤。
硬，是因为他要站着，要在官场里撑住，要在穷日子里撑住，要在所有想把他按倒的东西面前撑住。可撑住是要耗力气的，撑到最后，只剩下一个人的时候，那口气一松，雪就落满了山。
竹子咬定青山，是因为山里没有别人。 雪后站在门口的人，也是。
郑板桥的画里，竹子旁边经常有一块石头。竹是硬的，石是孤的。他自己就是那根竹子，也是那块石头。
# 06 对世界硬，对自己孤
我们很多人，都活成了郑板桥的前半首。
在外面，对工作硬，对生活硬，对所有不公硬；牙齿咬碎往肚里咽，人说一句，顶一句，绝不服软。
可是回到家，关上门，对着窗外的雪或者雨，会突然安静下来，觉得累，觉得冷，觉得没人懂。
这不是软弱。
这是一个人把力气都用来撑住世界之后，剩下的那一小会儿，留给自己清孤。
郑板桥告诉我们：这两种状态可以同时存在，而且本来就是一体的。
你对外面的硬，恰恰是因为你心里有一处不肯妥协的地方；你独处时的孤，恰恰是因为你不肯随大流，不肯跟这世界同流合污。
难得糊涂的人，最清醒。 画竹画得最刚的人，最懂孤独。
# 07 写在最后
1765年，郑板桥去世，终年73岁。
他一生没有大富大贵，死的时候还是个卖画的老头。可他把竹子画成了中国人的骨气，把"难得糊涂"四个字写进了中国人的心里。
他告诉后世的我们：
人这一生，既要像竹子一样，咬定青山不放松，任你东西南北风；
也要允许自己，在一个雪后的早晨，站在门口，感受那一种清孤不等闲。
硬，是给世界的。 孤，是留给自己的。
愿你也有竹子的硬，和懂你的孤。
